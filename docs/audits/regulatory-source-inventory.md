# Inventario de Fuentes Regulatorias Oficiales (Regulatory Source Inventory)

Este inventario documenta las fuentes oficiales primarias y secundarias de la legislación mexicana aplicables al Sistema de Ahorro para el Retiro (SAR) bajo el metamodelo de RAIA.

* **Nombre Corto**: Constitución
* **Tipo**: `constitution`

* **Última Reforma**: DOF 28-05-2026 (o vigente al día de consulta)
